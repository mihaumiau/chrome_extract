# chrome_extract

small utility script meant to extract chrome folders from https://google-chrome.en.uptodown.com/windows installers. (requires 7zip)

## usage:

place installers in the same directory as the script and run it.

````markdown
- chrome_extract.py
- google-chrome-151-0-7922-72.msi
- google-chrome-151.0-7922-138.msi
- ...
````
will extract to:

````markdown
- 151.0.7922.72/
- 151.0.7922.138/
- ...
- chrome_extract.py
- google-chrome-151-0-7922-72.msi
- google-chrome-151.0-7922-138.msi
- ...
````
